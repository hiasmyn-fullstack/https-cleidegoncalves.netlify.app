# Site Cleide Gonçalves
Site responsivo desenvolvido para apresentar os serviços profissionais da Cleide Gonçalves, publicado no Netlify.

## Tecnologias utilizadas
- HTML5: estrutura das páginas
- CSS3: estilo e layout responsivo (funciona em celular e computador)
- JavaScript: interações simples da página

## Funcionalidades
- Layout adaptado para todos os tamanhos de tela
- Apresentação profissional
- Galeria de imagens dos trabalhos
- Formulário de contato para clientes
- Navegação simples e intuitiva
